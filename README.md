# 🎮 ERRORCRAFT

Um mod desenvolvido para **Minecraft 26.3** utilizando o **Fabric Loader 0.20.1**.

---

## 📋 Requisitos

Antes de instalar o mod, certifique-se de ter:
* **Minecraft:** Versão `26.3`
* **Mod Loader:** [Fabric Loader](https://fabricmc.net) `0.20.1` ou superior
* **Dependências:** [Fabric API](https://modrinth.com) *(remova esta linha caso o mod não precise da API)*

---

## 🚀 Como Instalar

1. Baixe e instale o **Fabric Loader 0.20.1** para o Minecraft 26.3.
2. Baixe o arquivo `errorcraft-1.0.0.jar` aqui no repositório (ou na aba **Releases**).
3. Abra a pasta do seu Minecraft:
   * **Windows:** Pressione `Win + R`, digite `%appdata%\.minecraft` e aperte Enter.
   * **Linux:** `~/.minecraft`
   * **macOS:** `~/Library/Application Support/minecraft`
4. Coloque o arquivo `.jar` baixado dentro da pasta `mods` (se a pasta não existir, crie uma com esse nome).
5. Inicie o jogo selecionando o perfil do **Fabric** no launcher.
